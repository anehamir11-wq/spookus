Spookus 👻

About the Project

Spookus is a fun, interactive Halloween-themed browser game developed using JavaScript and the p5.js library.

The objective of the game is to click on the appearing tombstones to earn points before the 30-second timer runs out.

Features

* Simple and interactive gameplay.
* 30-second countdown timer.
* Score tracking system.
* Random tombstone positions.
* Particle effects when a target is clicked.
* Game Over screen displaying the final score.
* Option to restart and play again.

Technologies Used

* HTML5
* CSS3
* JavaScript
* p5.js
* p5.sound library (included in the project)

How I Built It

The game was developed using JavaScript and the p5.js library.

* HTML provides the basic webpage structure.
* CSS is used for styling.
* JavaScript handles the game logic, scoring, timer, and mouse interactions.
* p5.js is used to create the game canvas, draw graphics, and generate particle effects.

How to Play

1. Open the Spookus game in a web browser.
2. Click anywhere on the start screen to begin.
3. Click on the tombstone to increase your score.
4. Try to score as many points as possible within 30 seconds.
5. When the timer ends, your final score will appear.
6. Click again to restart the game.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Make sure you have an internet connection because the p5.js libraries are loaded through a CDN.

Project Files

* index.html – Main webpage.
* style.css – Styling.
* sketch.js – Main game logic and functionality.
* p5.js – p5.js library.
* p5.sound.min.js – p5.sound library.
